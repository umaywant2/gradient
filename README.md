# **gradient — Bring your idea into alignment**

- [`module.json`](https://raw.githubusercontent.com/umaywant2/gradient/refs/heads/main/module.json) — Agentic module schema role assignments

Gradient is the **alignment surface** for ideas entering the RTT lineage.

It provides a simple, declarative front door for the four foundational parameters:

- **rtt = 1**  
- **coherence = declared**  
- **drift = bounded**  
- **paradox = structural**

These four values define the *initial state* of an idea before it enters the RTT engines.

---

## **Purpose**

Gradient is the **pre‑engine layer** of TriadicFrameworks.

It does not transform the idea.  
It **declares** it.

Gradient ensures that every idea begins with:

- a structural RTT/1 footing  
- a declared coherence vector  
- a bounded drift envelope  
- a structural paradox frame  

This creates a stable starting point for downstream RTT engines.

## **How It Works**

1. You bring an idea.  
2. Gradient declares its four structural parameters.  
3. The idea is now *eligible* for RTT/1 processing.  
4. From there, the RTT lineage takes over.

Gradient is intentionally minimal.  
It is the **alignment gate**, not the engine.
